# Архитектура ZUI-TAD

## Идея

Обычный WM раскладывает окна по экрану: тайлинг режет его на слоты, стекинг
кладёт друг на друга. ZUI-TAD делает третье: **окна живут на бесконечном 2D-холсте
в своём натуральном размере, а экран — камера на этом холсте**. Рабочих столов нет
по построению; вместо них закладки камеры и кластеры сцепленных окон.

Слои:

```
   оболочка (phosphor)      панель · меню · справка · HUD · OSD · обои
   ────────────────────
   композитор (compositor)  wl_output · xdg_shell · pointer/keyboard · canvas-рендер
   ────────────────────
   модель холста            Scene: окна, кластеры, камера, взаимодействие
   (canvas-engine)
   ────────────────────
   объектная модель         RO/VO (TAD/BTRON), sled — окно как объект, плейсхолдеры
   (tad-core, de-common)
```

## Почему так разделено

* **`canvas-engine` не знает ни про Wayland, ни про GPU.** Камера, раскладка,
  Scene, snapping, resize-математика — чистые функции. Поэтому 46 тестов идут
  за миллисекунды без дисплея, и одна и та же логика работает и в композиторе,
  и в CPU-превью.
* **`phosphor` не знает про композитор.** Рисует в `tiny_skia::Pixmap`; превью
  кладёт пиксели в softbuffer, композитор (план) — в GL-текстуру через
  `MemoryRenderBuffer`. Один код — два потребителя.
* **Композитор держит только мост**: `xdg_toplevel ↔ WindowId` в `Scene`,
  перевод ввода в мировые координаты, `xdg configure` при ресайзе.

## Ключевые инварианты

1. `Scene` — единственный источник правды о геометрии окна (мировые координаты).
   Экранные координаты считаются на лету в `layout_windows` и нигде не хранятся.
2. Кластер существует ⇔ в нём ≥ 2 окна; окно, уехавшее в одиночку, выпадает.
3. Ресайз считается от СТАРТОВОГО прямоугольника (без накопления ошибки);
   тяга за левый/верхний край двигает окно, правый/нижний зафиксирован.
4. `PinnedToScreen` (PiP) игнорирует pan/zoom; `Widget` живёт на холсте, но ниже
   окон и вне Alt-Tab.
5. Фон — процедурный и кэшируется по размеру вьюпорта; параллакс — один блит.

## Производительность

CPU-рендер 1600×900, Ryzen 7 7840HS:

| | мс/кадр |
|---|---|
| до оптимизаций | ~41 (24 fps) |
| fused CRT + тайл шума | ~14 |
| + кэш растров карточек/панели, блит без ветвлений | **8.4–9.5** |
| + обои с параллаксом | ~12.5 (всё ещё внутри бюджета 16.6) |

Адаптивное качество: `AUTO` уходит в `LEAN` (сканлайны без зерна/дизеринга),
если средний кадр превышает 90% бюджета. Телеметрия видна в модуле `RIG`
(`FRAME`, `MODE`).
